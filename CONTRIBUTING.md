Thank you for your interest in contributing to **ARGUS**! We welcome contributions from developers, researchers, and open-source enthusiasts.

## How Can I Contribute?

### 1. Reporting Bugs
- Search existing GitHub Issues before opening a new one.
- Open an issue using a clear title, reproduction steps, expected behavior, and environment details (Node version, OS).

### 2. Suggesting Enhancements
- Feature requests and skill improvements are welcome!
- Provide clear context on how the enhancement improves developer productivity or code quality reviews.

### 3. Submitting Pull Requests
- Fork the repository and create your feature branch: `git checkout -b feature/my-amazing-feature`.
- Follow our coding standards:
  - Run `npm run lint` to check JS syntax across modules.
  - Run `npm test` (`node --test`) to ensure all skill unit tests pass cleanly.
- Ensure any new skills or pipeline steps are documented in `AGENTS_AND_SKILLS.md` and `architecture.md`.

## Local Development Setup

```bash
# Fork & Clone repository
git clone https://github.com/SahooShuvranshu/Argus.git
cd Argus

# Install dependencies
npm install

# Run syntax linting
npm run lint

# Run unit tests
npm test
```
