1. Getting Started & Installation Guide

ARGUS is designed to run automatically on every GitHub Pull Request. It fetches the PR git diff, changed files list, and repository architecture.md rules to output an idempotent executive review comment.

Step-by-Step Installation:

  1. Create a file named .github/workflows/argus.yml in your repository.
  2. Ensure GitHub Token permissions include pull-requests: write and contents: read.
  3. Add your preferred AI provider API key as a secret under Repository Settings ➔ Secrets and Variables ➔ Actions.
name: ARGUS AI Code Review

on:
  pull_request:
    types: [opened, synchronize, reopened]

jobs:
  argus-review:
    name: ARGUS 3-Stage AI PR Review
    runs-on: ubuntu-latest
    permissions:
      contents: read
      pull-requests: write
      issues: write

    steps:
      - name: Checkout Code
        uses: actions/checkout@v4

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: 'npm'

      - name: Install Dependencies
        run: npm ci

      - name: Run ARGUS AI Reviewer
        uses: SahooShuvranshu/Argus@main
        with:
          github-token: ${{ secrets.GITHUB_TOKEN }}
          gemini-api-key: ${{ secrets.GEMINI_API_KEY }}

2. Google Gemini Setup Manual (Default Recommended)

Google Gemini is natively integrated into ARGUS via the official @google/genai SDK. It offers extremely fast inference speed and requires **no custom base URL endpoint**.

Configuration Highlights:

  • Default Model: gemini-2.0-flash (fast, multimodal, 1M context window).
  • Input Parameter: Pass gemini-api-key: ${{ secrets.GEMINI_API_KEY }}.
  • No Endpoint Required: Automatically connects through Google's native API.
# Google Gemini Configuration
- name: Run ARGUS AI Reviewer
  uses: SahooShuvranshu/Argus@main
  with:
    github-token: ${{ secrets.GITHUB_TOKEN }}
    gemini-api-key: ${{ secrets.GEMINI_API_KEY }}
    model: "gemini-2.0-flash" # Optional override

4. Stage 1: Atlas Visualizer Mechanics

Inspired by the Titan Atlas who held up the structure of the cosmos, skills/atlas.js converts raw git diffs into an interactive Mermaid.js flowchart (flowchart TD).

It renders changed files, structural dependencies, and control flow updates inside a collapsible <details> element directly in the PR review comment.

5. Stage 2: Athena Architecture Guard Mechanics

Named after Athena, goddess of wisdom and military strategy, skills/athena.js acts as an automated Senior Software Architect.

It reads your repository's architecture.md rules and verifies that new PR diffs do not break layering rules, inject forbidden imports, or violate stack declarations.

6. Stage 3: Hermes Technical Debt Scanner Mechanics

Named after Hermes, the wing-footed messenger god who uncovered hidden secrets, skills/hermes.js inspects every line of modified code for technical debt and security leaks.

Hermes Severity Badges:

  • 🔴 BLOCK: Hardcoded API keys, tokens, or critical security vulnerabilities.
  • 🟡 WARN: Unfinished // TODO, // FIXME, or empty function stubs.
  • 🔵 INFO: Debugging statements (e.g. console.log).

7. Security Policy & Troubleshooting FAQ

Security Policy Highlights:

ARGUS is strictly configured to **never echo secret API keys or private tokens** into public PR comments or workflow log streams. Security reports can be sent to contact@sahooshuvranshu.is-a.dev.

Frequently Asked Questions:

Q: What happens if API quota (HTTP 429) occurs?
ARGUS features a built-in Fallback Static Analysis Engine. If the AI model key reaches quota limits or network errors occur, ARGUS seamlessly uses static regex analysis to complete the PR review without breaking your CI pipeline.


Q: How do I test ARGUS locally before opening PRs?
Run npm run lint for syntax verification and npm test to execute the native test suite.
